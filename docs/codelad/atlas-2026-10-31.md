# Atlas call-map milestone

The user selected Atlas code graph on 2026-10-31. The first relationship type is actual caller/callee data from the installed language provider's existing call-hierarchy API. Atlas is a registered native workbench editor, with normal editor groups and source navigation through `IEditorService`. No web dashboard, embedded browser, parser package or background repository index is introduced. [Direction contract](design/atlas-direction.md) extends the existing Quiet Shell / Graphite design.

## Behavior

Open Code Atlas uses the function or method at the current source caret, opens its actual provider-backed map and keeps source alongside. Select a node to inspect its location and loaded call sites. Expand Callers / Expand Callees grows the loaded graph progressively. Each edge points from caller to callee; call-site buttons open the provider's actual caller range. Equal source selections deduplicate across incoming/outgoing results, while recursive edges and same-named symbols at different locations remain distinct.

The graph is bounded to 80 symbols and 160 edges, with at most 200 relationships processed per provider response and 32 stored call-site ranges per edge. Truncated results are disclosed. Filters apply to loaded relationships, names/paths and files reported changed by existing SCM. The source anchor stays visible for orientation. The minimap displays actual node positions and the actual viewport; it is not a decorative image. Zoom, fit and Toggle Map Focus operate on the real map/editor group. Narrow layouts put the inspector below the map and retain its controls and call-site access.

Atlas cancels superseded requests and releases provider sessions/model references when closed. Changes to observed open source models mark the snapshot stale and require refresh before expansion. A closed file changing outside the loaded models is not a universal change-detection guarantee; refresh when source changes. Restoring Atlas persists only the source URI/position and waits for Refresh from Anchor, avoiding an automatic graph query during startup. Existing language providers retain their own network behavior and trust boundaries; Atlas is not an extension firewall.
